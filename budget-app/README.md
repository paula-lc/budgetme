# Presupuesto

Una app sencilla para gestionar tu presupuesto de gastos, estilo hoja de cálculo.

## Qué hace

- Dos pestañas tipo Excel: **Gastos fijos** y **Gastos variables**.
- Edición directa de celdas (categoría e importe), como en una hoja de cálculo.
- Totales automáticos por tipo de gasto y total general.
- Barra visual que muestra la proporción entre gastos fijos y variables.
- Guardado automático en el navegador — no necesita backend ni base de datos.

## Cómo usarla

Abre `index.html` en cualquier navegador. No requiere instalación ni build.

### Publicarla con GitHub Pages

1. Ve a **Settings → Pages** en este repositorio.
2. En "Source", selecciona la rama `main` y la carpeta `/ (root)`.
3. Guarda. En unos minutos la app estará disponible en:
   `https://<tu-usuario>.github.io/<nombre-del-repo>/`
